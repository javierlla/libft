# 🧠 Lbft – Proyecto de Iniciación en C @ 42

`Lbft` es el primer proyecto del programa 42, diseñado para introducir los conceptos fundamentales de la programación en lenguaje C. Su objetivo es que el estudiante aprenda a manejar punteros, estructuras básicas, control de flujo y la lógica de programación desde cero.

---

## 📌 Objetivos del proyecto

- Entender la compilación y ejecución de programas en C.
- Escribir funciones usando punteros y variables.
- Trabajar con la memoria y entender cómo funciona.
- Aprender las buenas prácticas de codificación y normas del estilo de código 42.

---

## 🛠️ Contenidos clave

- Tipos de datos en C
- Declaración y uso de funciones
- Punteros y manipulación de memoria
- Bucles, condicionales y estructuras básicas
- Compilación con `Makefile`

---

## 🚀 Cómo ejecutar el proyecto

Clona este repositorio y compílalo con `make`:

```bash
git@github.com:javierlla/libft.git
cd 01-Libft
make
./lbft
